# Starlink 3D Tracker - v1.0.0

这是一个基于 React + Three.js + Vite 构建的实时 3D 星链卫星追踪系统。

## v1 版本核心特性
- **实时卫星追踪**：对接 CelesTrak TLE 数据，实时计算 9000+ 颗卫星的轨道位置。
- **高性能矢量渲染**：采用自定义 GPU Shader 实现 sharp-edge 矢量点阵效果，支持 60FPS 流畅运行。
- **全方位时间控制**：支持模拟时间的加速（最高 500x）、暂停及倒流，并配有实时时钟。
- **交互式数据面板 (HUD)**：
    - **点击锁定**：点击任意卫星即可展示其未来 95 分钟的预测轨道线。
    - **实时数据**：显示选中卫星的 NORAD ID、发射年份、高度及实时运行速度（km/h）。
- **四角 UI 布局**：优化的交互界面，最大化地球视觉展示区域。
- **LOD 细节过渡**：远景显示点阵，极近距离自动切换为高精度 3D 卫星模型。
- **视觉增强**：
    - **高度热力图**：根据卫星真实高度进行颜色编码（红色代表低轨，青色代表高轨）。
    - **地球夜景**：支持城市灯光贴图。
    - **酷炫开场**：雷达扫描加载动画及卫星随机闪烁登场特效。

## 运行方式
1. 安装依赖：`npm install`
2. 启动开发服务器：`npm run dev`
3. 访问链接：`http://localhost:5173`
